# orderSystem
Реализация системы заказов на архитектуре слоеного пирога

## Деньги

Все денежные суммы хранятся целыми числами в копейках. Например, 1000 рублей
50 копеек представлены значением `100_050`. В HTTP API единица измерения
зафиксирована в названиях полей: `price_kopecks` и `total_sum_kopecks`.
